# 🖥️ GestãoPro — Frontend

Interface web do GestãoPro, desenvolvida com Angular e integrada à API REST do Management System.

O projeto permite visualizar e gerenciar as principais funcionalidades do sistema, como produtos, clientes, vendas e estoque.

---

## ✨ Funcionalidades

- Gerenciamento de produtos
- Gerenciamento de clientes
- Registro e acompanhamento de vendas
- Controle de estoque
- Dashboard com acompanhamento de vendas e estoque
- Login de usuários

---

## 🛠️ Tecnologias utilizadas

- Angular 19
- TypeScript 5.7
- HTML
- SCSS
- Bootstrap 5
- RxJS
- Angular Router
- Angular HttpClient
- Chart.js

---

## ▶️ Como executar o projeto

### Pré-requisitos

- Node.js
- npm
- Angular CLI

### Instalar dependências

```bash
npm install
```

### Executar aplicação

```bash
ng serve
```

A aplicação estará disponível em:

```txt
http://localhost:4200
```
